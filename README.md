# lecture07-ml — OOP in Python · Lecture 7 (Part 1)

Part 1 of the Object-Oriented Programming lecture: **polymorphism and
encapsulation**, taught on fintech/banking examples (payment gateways,
bank accounts, cards). A 64-slide presentation in three languages, plus
two Jupyter notebooks for practice.

## Topics covered

- **Recap of Lecture 6** — classes, objects, attributes, methods,
  `__init__`/`self`, namespace isolation, `__str__`, inheritance, `super()`
- **Polymorphism** — method overriding, the root `object` class, the
  Diamond Problem, MRO and `__mro__`, duck typing
- **Encapsulation** — the `_protected` convention, `__private` name
  mangling, `@property` getters, validating setters
- **Class-level data** — instance vs class attributes
